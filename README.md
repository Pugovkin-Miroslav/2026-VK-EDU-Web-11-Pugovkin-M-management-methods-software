# Local Chat - приложение для поиска временных чатов поблизости
 Бизнес-модель: B2В
# Задание 1
Elevator Pitch

Люди, посещающие концерты, фестивали, университеты и другие общественные места, часто хотят познакомиться с окружающими или обсудить происходящее, но не имеют удобного способа найти людей с похожими интересами поблизости. Я предлагаю Local Chat - приложение для общения с людьми, объединёнными общим местоположением или событием. Главная особенность приложения - интерактивная карта, на которой пользователи могут создавать временные чаты в любой точке мира и присоединяться к ним, находясь в заданном радиусе. После вступления общаться можно независимо от местоположения, а по истечении срока жизни чат закрывается и сохраняется в архиве участников. В результате пользователи смогут легко находить новые знакомства, обсуждать мероприятия и поддерживать связь после их завершения. Монетизация будет осуществляться по B2B-модели за счёт геотаргетированной рекламы: компании смогут выбирать области на карте и размещать рекламу в расположенных там чатах.
